# covid19-trend-analysis# COVID-19 Trend Analysis and Forecasting using Python & Prophet

## Project Overview
This project analyzes global COVID-19 data to understand infection trends, recovery rates, and death rates. It also predicts future cases using a time series forecasting model.

## Tools & Technologies
- Python
- Pandas
- Plotly
- Prophet

## Key Features
- Data cleaning and preprocessing
- Feature engineering (New Cases, Recovery Rate, Death Rate)
- Interactive visualizations using Plotly
- 7-day moving average analysis
- Time series forecasting using Prophet

## Key Insights
- Infection rates increased rapidly during early stages
- Recovery rate improved over time
- Death rate gradually decreased
- Moving average helped identify actual trends

## Forecasting
- Used Prophet model to predict COVID-19 cases for the next 7 days
- Included confidence intervals for better understanding of uncertainty

## Dataset
- COVID-19 dataset containing confirmed, recovered, and death cases worldwide
